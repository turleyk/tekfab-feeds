# tekfab-feeds

Public product feeds for TekFab, served by GitHub Pages at https://feeds.tekfab.co.uk/

| File | What it is |
|------|------------|
| `googleMerchant.xml` | Google Merchant Center product feed (XML; one element per image). Built automatically from the private `tekfab-product-data` repo (workflow "Merchant Center feed") whenever product data or the feed rules change. Do not edit here. |

Only public product information is published here. This repo is kept separate from the shop's scripts so the token that updates it cannot change the shop.
